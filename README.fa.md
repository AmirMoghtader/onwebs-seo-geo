## چرا این به‌جای Screaming Frog؟

دیگر لازم نیست برای کراول کامل سایت Screaming Frog بخرید. این ابزار **رایگان و متن‌باز** است، محدودیت تعداد URL ندارد و همان خروجی را با امکانات بیشتر می‌دهد:

| | **Onwebs SEO & GEO** | Screaming Frog |
|---|---|---|
| قیمت | **رایگان برای همیشه** | ۲۵۹ پوند در سال |
| محدودیت کراول | **نامحدود** | ۵۰۰ آدرس در نسخه‌ی رایگان |
| کد منبع | **باز (GPL-3)** | بسته |
| تب Internal | **هر ۷۳ ستون، معادل دقیق** | ۷۳ ستون |
| زنجیره‌ی ریدایرکت به‌صورت ردیف | ✅ | ✅ |
| Include/Exclude و حالت لیست | ✅ | ✅ |
| کنترل سرعت کراول | ✅ سه پروفایل یک‌کلیکی | ✅ |
| تحلیلگر لاگ سرور | ✅ **داخل خود اپ + رهگیری بات‌های AI** | محصول جداگانه‌ی پولی |
| GEO / آمادگی برای جستجوی AI | ✅ رهگیری GPTBot، ClaudeBot، PerplexityBot | ❌ |
| اتصال PageSpeed، GA4، سرچ‌کنسول، Clarity | ✅ | ناقص (پولی) |
| شبیه‌ساز گوگل‌ادز و مبدل تصویر | ✅ | ❌ |
| رابط فارسی | ✅ کاملاً فارسی | ❌ |
| تله‌متری | **صفر — داده‌ها از سیستم شما خارج نمی‌شود** | — |

موتور کراولر با **Rust** نوشته شده (سریع و کم‌مصرف)، رابط با **Next.js** و بسته‌بندی با **Tauri** — کل اپ حدود ۲۵ مگابایت است و در حالت بیکار فقط ~۵۷ مگابایت رم می‌گیرد.

## امکانات

- **کراولر عمیق** با ست کامل ستون‌های تب Internal اسکریمینگ‌فراگ (۷۳ ستون)، نمایش یکجای صفحات + تصاویر + JS + CSS، تب‌های فیلتر بر اساس Content Type، انتخاب‌گر ستون و خروجی CSV کامل
- **سورت سه‌حالته با کلیک روی هر ستون**، مرتب‌سازی فارسی‌آگاه
- **زنجیره‌ی ریدایرکت** به‌صورت ردیف‌های جدا با استتوس‌کد واقعی 3xx
- **پروفایل‌های سرعت کراول**: محتاط / متعادل / سریع (تا ۱۶ درخواست هم‌زمان، بدون تأخیر روی سایت خودتان، عقب‌نشینی خودکار روی 429/503)
- **کراولر تک‌صفحه** برای ممیزی سریع: Core Web Vitals، تحلیل Head، پیش‌نمایش SERP و OpenGraph، خوانایی، چگالی کلمات کلیدی
- **کاوشگر مشکلات** مرتب بر اساس اهمیت + نمای کلی با باکس‌های کلیک‌پذیر
- **تحلیل سایت‌مپ XML**، بررسی robots.txt، تشخیص صفحات یتیم
- **تحلیلگر لاگ سرور** با تفکیک بات‌های ایندکس، ایجنت‌های بازیابی و بات‌های AI (GPTBot، OAI-SearchBot، ClaudeBot، PerplexityBot و…)
- **اتصال‌ها**: PageSpeed Insights، گوگل آنالیتیکس ۴، سرچ‌کنسول، Microsoft Clarity، Power BI، Ollama و Gemini (تحلیل هوشمند لوکال)
- **گزارش‌ها**: PDF کامل کراول، PDF لاگ سرور، خروجی‌های CSV به سبک گزارش‌های اسکریمینگ‌فراگ، Bulk Export
- **ذخیره و بازکردن کراول** به‌صورت فایل + تاریخچه‌ی کراول با مقایسه‌گر تفاوت
- **منوی native مک** با میانبرهای کراول (⌘↩ شروع، ⌘P مکث، ⌘. توقف)
- **رابط دوزبانه‌ی فارسی‌محور** (انگلیسی هم موجود)

## حریم خصوصی

بدون تله‌متری، بدون آنالیتیکس، بدون ارسال داده. چت عمومی، باکس پیشنهاد و آپدیت‌چکر ریموتِ نسخه‌ی اصلی بعد از ممیزی امنیتی **حذف شده‌اند**. داده‌های کراول در دیتابیس لوکال روی سیستم خودتان می‌ماند.

## بر پایه‌ی RustySEO

این پروژه فورکی از [RustySEO](https://github.com/mascanho/RustySEO) ساخته‌ی mascanho است با لایسنس GPL-3.0 (همین لایسنس حفظ شده). مهم‌ترین اضافات این فورک:

- معادل‌سازی کامل **۷۳ ستون** تب Internal + نمای یکپارچه‌ی صفحات و asset‌ها + خروجی CSV کامل
- سورت کلیکی همه‌ی جدول‌ها، ردیف‌های ریدایرکت، شمارش inlink
- استخراج‌های جدید: Meta Keywords، X-Robots-Tag، هدر Link، نسخه‌ی HTTP، بایت انتقالی، هش MD5، زمان کراول، شمارش جمله‌ها دقیقاً برابر اعداد اسکریمینگ‌فراگ
- الگوهای Include/Exclude، حالت لیست، توقف/مکث واقعی کراول
- پروفایل‌های سرعت و پیش‌فرض‌های بازنویسی‌شده (~۱۰ برابر سریع‌تر روی سایت خودتان)
- منوی native مک، اصلاح اندازه‌ی پنجره، داشبورد جمع‌وجور
- فارسی‌سازی کامل رابط
- سخت‌سازی حریم خصوصی: حذف endpointهای شخص ثالث و کلیدهای API هاردکد
- صفر کردن خطاهای کنسول/hydration در همه‌ی صفحات
